# Фразы для писем (Redemittel)

Универсальные фразы для всех видов писем на DTZ: формальных (Sie) и неформальных (du). Выбирай фразы, которые звучат хорошо и используются в реальной жизни. Правила письма — на странице [Правила письма](#/dtz/pisma-pravila).

## 1. Обращение и прощание

| Formell (Sie) | Informell (du) |
| --- | --- |
| Sehr geehrter Herr Schneider, | Lieber Max, / Liebe Anna, |
| Sehr geehrte Frau Müller, | Hallo Max, |
| Sehr geehrte Damen und Herren, | Hi Anna, |
| Mit freundlichen Grüßen | Liebe Grüße |
| Freundliche Grüße | Viele Grüße |
| Mit freundlichen Grüßen und vielen Dank im Voraus | Bis bald! / Bis dann! |
|  | Ganz liebe Grüße / Alles Liebe |

После обращения стоит запятая, а следующая строка начинается с маленькой буквы: *Sehr geehrter Herr Schneider, ich schreibe Ihnen…*

## 2. Вступление: зачем пишешь

Первый абзац закрывает пункт «Grund für Ihr Schreiben». 1–2 предложения.

### Formell

| По-немецки | Значение |
| --- | --- |
| Ich schreibe Ihnen, weil … | Пишу вам, потому что… |
| Ich wende mich an Sie, weil … / wegen … | Обращаюсь к вам, потому что… / по поводу… |
| Ich möchte Sie über … informieren. | Хочу сообщить вам о… |
| Leider muss ich mich über … beschweren. | К сожалению, вынужден пожаловаться на… |
| Ich habe eine Frage zu … | У меня вопрос по поводу… |
| Vielen Dank für Ihr Schreiben vom 10. November. | Спасибо за ваше письмо от 10 ноября. |
| Wie ich Ihnen bereits am Telefon gesagt habe, … | Как я уже говорил вам по телефону… |
| Ich habe Ihre Anzeige gelesen und interessiere mich für … | Я прочитал ваше объявление и интересуюсь… |

### Informell

| По-немецки | Значение |
| --- | --- |
| Vielen Dank für deine E-Mail! | Спасибо за письмо! |
| Ich habe mich sehr über deine Nachricht gefreut. | Я очень обрадовался твоему сообщению. |
| Schön, mal wieder von dir zu hören! | Рад снова тебя слышать! |
| Wie geht es dir? Mir geht es gut. | Как дела? У меня всё хорошо. |
| Tut mir leid, dass ich mich erst jetzt melde. | Извини, что пишу только сейчас. |
| Ich schreibe dir, weil … | Пишу тебе, потому что… |
| Stell dir vor, …! | Представь, …! |

## 3. Проблема, жалоба, просьба

### Описать проблему

| По-немецки | Значение |
| --- | --- |
| Seit zwei Wochen funktioniert … nicht mehr. | Уже две недели … не работает. |
| … ist kaputt / defekt. | … сломан(а). |
| Ich habe ein Problem mit … | У меня проблема с… |
| Leider hat sich bis heute nichts geändert. | К сожалению, до сих пор ничего не изменилось. |
| Ich habe Sie bereits angerufen, aber seitdem ist nichts passiert. | Я уже звонил, но с тех пор ничего не произошло. |
| Ich bin mit … leider nicht zufrieden. | Я, к сожалению, недоволен… |
| Das ist für mich ein großes Problem, weil … | Для меня это большая проблема, потому что… |

### Попросить (пункт «Was Sie wollen»)

| Formell (Sie) | Informell (du) |
| --- | --- |
| Ich möchte Sie bitten, … zu … | Kannst du bitte …? |
| Könnten Sie bitte …? | Könntest du mir einen Gefallen tun? |
| Wären Sie so freundlich, … zu …? | Es wäre super, wenn du … könntest. |
| Es wäre sehr nett, wenn Sie … könnten. | Hast du vielleicht Zeit, …? |
| Ich erwarte, dass Sie … bis zum 30. November … | Sag mir bitte Bescheid, ob … |
| Bitte teilen Sie mir mit, wann … | Schreib mir einfach, wann … |

Запомни: *bitten, … **zu** + инфинитив* (без *um*). *Ich möchte Sie bitten, die Fenster zu reparieren.*

## 4. Согласие, отказ, предложение, извинение, вопрос

Слева формально (Sie), справа неформально (du). Смысл по строкам: помочь, отказать, предложить, извиниться, спросить, поблагодарить, пожелать.

| Formell (Sie) | Informell (du) |
| --- | --- |
| Gern helfe ich Ihnen bei … | Na klar helfe ich dir! / Das mache ich gern! |
| Ich bin gern bereit, … zu … | Kein Problem, das ist doch selbstverständlich. |
| Leider kann ich … nicht, weil … | Es tut mir echt leid, aber ich kann leider nicht. |
| Ich muss Ihnen leider absagen. | Ich würde gern kommen, aber … |
| Ich schlage vor, dass … | Wie wäre es, wenn wir …? |
| Wäre es möglich, dass …? | Was hältst du davon, wenn …? |
| Darf ich vorschlagen, … | Wollen wir …? / Lass uns …! |
| Ich möchte mich für … entschuldigen. | Sorry, dass … / Es tut mir leid, dass … |
| Bitte entschuldigen Sie die Verspätung. | Sei mir bitte nicht böse! |
| Könnten Sie mir bitte sagen, ob / wann / wo …? | Weißt du schon, wann …? |
| Ich hätte noch eine Frage: … | Und noch eine Frage: … |
| Wo finde ich …? / Wann passt es Ihnen? | Wann passt es dir am besten? |
| Vielen Dank für Ihre Hilfe / Ihr Verständnis. | Danke dir! Das ist echt nett von dir. |
| Ich wünsche Ihnen alles Gute. | Ich wünsche dir einen schönen Urlaub! / Gute Besserung! |

## 5. Причины и последствия

### Объяснить, почему это важно или плохо

| По-немецки | Значение |
| --- | --- |
| Das ist wichtig für mich, weil … | Это важно для меня, потому что… |
| Ein großer Nachteil ist, dass … | Большой минус в том, что… |
| Außerdem kommt noch hinzu, dass … | К тому же добавляется то, что… |
| Das führt dazu, dass … | Это приводит к тому, что… |
| Ich habe Angst, dass … | Я боюсь, что… |
| Wenn …, dann … | Если…, то… |

### Что сделаешь, если ничего не изменится (типичный пункт в жалобах)

Всегда с конкретным сроком: *bis Freitag*, *innerhalb von drei Tagen*.

| По-немецки | Значение |
| --- | --- |
| Falls sich bis … nichts ändert, werde ich … | Если до… ничего не изменится, я… |
| Sonst sehe ich mich gezwungen, … zu … | Иначе я буду вынужден… |
| … mich an den Mieterverein / einen Anwalt wenden. | …обратиться в союз арендаторов / к адвокату |
| … die Miete kürzen. | …уменьшить оплату аренды |
| … selbst einen Handwerker beauftragen und Ihnen die Rechnung schicken. | …сам вызвать мастера и прислать вам счёт |
| … mein Geld zurückverlangen. | …потребовать деньги назад |
| … den Vertrag kündigen. | …расторгнуть договор |

## 6. Завершение и связки

| Formell (Sie) | Informell (du) |
| --- | --- |
| Ich freue mich auf Ihre Antwort. | Ich freue mich auf deine Antwort! |
| Über eine baldige Antwort würde ich mich sehr freuen. | Schreib mir bald! |
| Vielen Dank im Voraus. | Melde dich einfach! |
| Für Rückfragen stehe ich Ihnen gern zur Verfügung. | Ruf mich an, wenn du Fragen hast. |
| Vielen Dank für Ihr Verständnis. | Ich freue mich schon auf unser Treffen! |

*freuen auf* = жду с радостью (будущее). *freuen über* = радуюсь тому, что есть; с *würde* пишется *über*.

### Связки (Konnektoren)

| Зачем | Связки | Порядок слов |
| --- | --- | --- |
| Причина | weil, da | глагол в конце |
| Причина | denn | обычный порядок |
| Следствие | deshalb, deswegen, darum | глагол сразу после связки |
| Добавить | außerdem, zusätzlich, außerdem noch | глагол сразу после связки |
| Противопоставить | aber, sondern | обычный порядок |
| Уступка | trotzdem | глагол сразу после связки |
| Уступка | obwohl | глагол в конце |
| Условие | wenn, falls | глагол в конце |
| Цель | damit / um … zu | глагол в конце / zu + инфинитив в конце |
| Порядок | zuerst, dann, danach, zum Schluss | глагол сразу после связки |
| Время | während, nachdem, bevor | глагол в конце |

В каждом письме старайся использовать 5–6 разных связок. Это даёт баллы за критерий II.
