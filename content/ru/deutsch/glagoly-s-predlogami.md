# Глаголы с предлогами и похожие слова

У многих немецких глаголов свой закреплённый предлог. Его учат вместе с глаголом.

## Глагол + предлог

| Глагол | Падеж | Пример |
| --- | --- | --- |
| informieren **über** | Akkusativ | Ich möchte Sie über den Termin informieren. |
| sich erkundigen **nach** | Dativ | Ich möchte mich nach dem Programm erkundigen. |
| sich erinnern **an** | Akkusativ | Ich erinnere mich an den Tag. |
| danken **für** | Akkusativ | Vielen Dank für Ihre Hilfe. |
| helfen **bei** | Dativ | Könnten Sie mir beim Aufbau helfen? |
| einverstanden sein **mit** | Dativ | Ich bin damit einverstanden. |
| halten **von** | Dativ | Was halten Sie davon? |
| abhängen **von** | Dativ | Das hängt davon ab, ob … |
| ankommen **auf** | Akkusativ | Es kommt darauf an, ob … |
| sich melden **bei** | Dativ | Melden Sie sich gern bei mir. |
| sich wenden **an** | Akkusativ | Bei Fragen wenden Sie sich bitte an mich. |
| sich freuen **auf** | Akkusativ | Ich freue mich auf Ihre Antwort. |
| Bezug nehmen **auf** | Akkusativ | Bezugnehmend auf unser Gespräch … |

Без предлога, но с нужным падежом:

- **helfen, schreiben, dankbar sein** + Dativ: *Ich schreibe Ihnen. Ich wäre Ihnen dankbar.*
- **bitten, informieren** + Akkusativ: *Ich möchte Sie bitten, …*

## darüber, davon, darauf, damit

Когда после предлога идёт целое предложение (dass…, ob…), предлог превращается в **da(r) + предлог**:

- über → **darüber**: Ich möchte Sie darüber informieren, dass …
- von → **davon**: Das hängt davon ab, ob …
- auf → **darauf**: Es kommt darauf an, ob …
- mit → **damit**: Ich bin damit einverstanden, dass …

## Похожие слова, которые я путаю

### Узнать

| Слово | Значение |
| --- | --- |
| sich erkundigen nach | поинтересоваться, запросить информацию |
| erfahren | узнать новость: *Ich habe erfahren, dass …* |
| erkunden | исследовать (город, местность) |
| entwickeln | развивать, разрабатывать |

Проще всего: *Ich möchte fragen, ob …*

### Упомянуть, напомнить, запомнить

| Слово | Значение |
| --- | --- |
| erwähnen | упомянуть |
| jemanden an etwas erinnern | напомнить кому-то о чём-то |
| sich erinnern an | помнить |
| merken | заметить |
| sich merken | запомнить |
| darauf hinweisen, dass … | обратить внимание на то, что… |
| betonen | подчеркнуть |

### Обратиться

- **sich melden bei** — дать о себе знать, написать или позвонить. Обычнее и дружелюбнее.
- **sich wenden an** — обратиться за помощью или ответом. Официальнее.

### Услышать и увидеть

- **von jemandem hören** — получить от человека ответ, весточку.
- **jemanden sehen** — увидеться лично.

## Точные слова вместо приблизительных

| Я написал | Лучше | Почему |
| --- | --- | --- |
| das Einkaufen | die Einkäufe | конкретные покупки, а не процесс |
| gemacht | erledigt | «выполнено» |
| lernen (в школе) | Unterricht haben | у детей уроки |
| nach dem Feiern | nach der Feier | после праздника |
| zurück packen | wieder einpacken | упаковать обратно |
| eine Rückmeldung schreiben | eine Rückmeldung geben | устойчивое сочетание |
| werden gerne eingeladen | sind herzlich eingeladen | формула приглашения |
| was für Geld | wie viel | вопрос о сумме |

## Kinder или Kindern

- **Kinder** — Nominativ и Akkusativ множественного числа: *alle Kinder, unsere Kinder*.
- **Kindern** — только Dativ: *mit den Kindern, bei den Kindern*.

В Dativ множественного числа почти все существительные получают -n: *bei den Spielen, mit den Eltern*.
