# Как устроен этот сайт

Здесь собирается всё полезное из моих чатов с Claude по немецкому.

## Два раздела

| Раздел | Что внутри |
| --- | --- |
| **DTZ — экзамен** | Формат экзамена, письма, устная часть, разборы экзаменационных заданий |
| **Немецкий язык** | Грамматика, слова и выражения, домашние задания |

## Как добавить новое

1. Спросить что-нибудь у Claude в обычном чате, как раньше.
2. В Claude Code сказать: **«обработай немецкий»**.
3. Claude разберёт новые чаты и добавит всё сюда.

> Чаты удаляются только после моего «да».

## Удобства

- **Поиск** сверху ищет по всем страницам сразу.
- Справа — оглавление страницы.
- Кнопка с солнцем переключает тёмную тему.
