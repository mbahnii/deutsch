# Дієслова з прийменниками та схожі слова

У багатьох німецьких дієслів є закріплений прийменник. Його вчать разом із дієсловом.

## Дієслово + прийменник

| Дієслово | Відмінок | Приклад |
| --- | --- | --- |
| informieren **über** | Akkusativ | Ich möchte Sie über den Termin informieren. |
| sich erkundigen **nach** | Dativ | Ich möchte mich nach dem Programm erkundigen. |
| sich erinnern **an** | Akkusativ | Ich erinnere mich an den Tag. |
| danken **für** | Akkusativ | Vielen Dank für Ihre Hilfe. |
| helfen **bei** | Dativ | Könnten Sie mir beim Aufbau helfen? |
| einverstanden sein **mit** | Dativ | Ich bin damit einverstanden. |
| halten **von** | Dativ | Was halten Sie davon? |
| abhängen **von** | Dativ | Das hängt davon ab, ob … |
| ankommen **auf** | Akkusativ | Es kommt darauf an, ob … |
| sich melden **bei** | Dativ | Melden Sie sich gern bei mir. |
| sich wenden **an** | Akkusativ | Bei Fragen wenden Sie sich bitte an mich. |
| sich freuen **auf** | Akkusativ | Ich freue mich auf Ihre Antwort. |
| Bezug nehmen **auf** | Akkusativ | Bezugnehmend auf unser Gespräch … |

Без прийменника, але з потрібним відмінком:

- **helfen, schreiben, dankbar sein** + Dativ: *Ich schreibe Ihnen. Ich wäre Ihnen dankbar.*
- **bitten, informieren** + Akkusativ: *Ich möchte Sie bitten, …*

## darüber, davon, darauf, damit

Коли після прийменника йде ціле речення (dass…, ob…), прийменник перетворюється на **da(r) + прийменник**:

- über → **darüber**: Ich möchte Sie darüber informieren, dass …
- von → **davon**: Das hängt davon ab, ob …
- auf → **darauf**: Es kommt darauf an, ob …
- mit → **damit**: Ich bin damit einverstanden, dass …

## Схожі слова, які я плутаю

### Дізнатися

| Слово | Значення |
| --- | --- |
| sich erkundigen nach | поцікавитися, запитати інформацію |
| erfahren | дізнатися новину: *Ich habe erfahren, dass …* |
| erkunden | досліджувати (місто, місцевість) |
| entwickeln | розвивати, розробляти |

Найпростіше: *Ich möchte fragen, ob …*

### Згадати, нагадати, запам'ятати

| Слово | Значення |
| --- | --- |
| erwähnen | згадати |
| jemanden an etwas erinnern | нагадати комусь про щось |
| sich erinnern an | пам'ятати |
| merken | помітити |
| sich merken | запам'ятати |
| darauf hinweisen, dass … | звернути увагу на те, що… |
| betonen | підкреслити |

### Звернутися

- **sich melden bei** — дати про себе знати, написати чи зателефонувати. Звичайніше й дружніше.
- **sich wenden an** — звернутися по допомогу чи відповідь. Офіційніше.

### Почути та побачити

- **von jemandem hören** — отримати від людини звістку, відповідь.
- **jemanden sehen** — побачитися особисто.

## Точні слова замість приблизних

| Я написав | Краще | Чому |
| --- | --- | --- |
| das Einkaufen | die Einkäufe | конкретні покупки, а не процес |
| gemacht | erledigt | «виконано» |
| lernen (у школі) | Unterricht haben | у дітей уроки |
| nach dem Feiern | nach der Feier | після свята |
| zurück packen | wieder einpacken | запакувати назад |
| eine Rückmeldung schreiben | eine Rückmeldung geben | усталене сполучення |
| werden gerne eingeladen | sind herzlich eingeladen | формула запрошення |
| was für Geld | wie viel | питання про суму |

## Kinder чи Kindern

- **Kinder** — Nominativ і Akkusativ множини: *alle Kinder, unsere Kinder*.
- **Kindern** — лише Dativ: *mit den Kindern, bei den Kindern*.

У Dativ множини майже всі іменники отримують -n: *bei den Spielen, mit den Eltern*.
