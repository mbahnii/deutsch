# Фрази для розмови

Короткі фрази, щоб пояснити, про що мова, і висловити свою думку. Підходять і для іспиту, і для звичайної розмови.

## Я просто питаю

| Німецькою | Значення | Коли |
| --- | --- | --- |
| Ich frage nur. | Я просто питаю. | завжди |
| Ich frage einfach nur. | Я просто запитую. | завжди |
| Ich wollte nur mal fragen. | Я лише хотів спитати. | у розмові |

## Про що йдеться

| Німецькою | Значення | Відмінок |
| --- | --- | --- |
| Es geht darum, dass … | Йдеться про те, що … | — |
| Hier geht es um … | Тут ідеться про … | Akkusativ |
| Das betrifft … | Це стосується … | Akkusativ |
| Es handelt sich um … | Мова йде про … | Akkusativ |
| Der Text handelt von … | Текст розповідає про … | Dativ |

- *Hier geht es um **den** Garten.*
- *Das betrifft **den** Balkon.*
- *Der Text handelt **von dem** (vom) Umzug.*

## Що стосується …

- *Was den Garten **angeht**, …* — що стосується саду, …
- *Was den Garten **betrifft**, …* — те саме, трохи офіційніше (добре для іспиту).
- *… und so weiter (usw.)* — і так далі.

## Історія про …

- *eine Geschichte **über** + Akkusativ* — *eine Geschichte über den Krieg*
- *die Geschichte **von** + Dativ* — *die Geschichte von meiner Familie*

## З одного боку … з іншого боку …

- ***Einerseits** …, **andererseits** …*
- ***Auf der einen Seite** …, **auf der anderen Seite** …*

Приклад для іспиту: *Einerseits ist ein Balkonkasten schön, andererseits braucht er viel Pflege.*

Після *einerseits* / *andererseits* дієслово стоїть одразу: *einerseits **ist** …*.

## «Хай кине в мене камінь той, хто …»

- *Wer glaubt, dass …, der soll den ersten Stein werfen.* — біблійний вислів, німці кажуть так рідко.

Простіше в розмові:

- *Wer das anders sieht, soll es sagen.* — Хто думає інакше, хай скаже.
- *Ich glaube nicht, dass jemand denkt, dass …* — Не думаю, що хтось вважає, що …
