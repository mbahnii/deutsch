# Фрази для листів (Redemittel)

Універсальні фрази для всіх видів листів на DTZ: формальних (Sie) і неформальних (du). Вибирай фрази, які чудово звучать і вживаються в реальному житті. Правила листа — на сторінці [Правила листа](#/dtz/pisma-pravila).

## 1. Звертання і прощання

| Formell (Sie) | Informell (du) |
| --- | --- |
| Sehr geehrter Herr Schneider, | Lieber Max, / Liebe Anna, |
| Sehr geehrte Frau Müller, | Hallo Max, |
| Sehr geehrte Damen und Herren, | Hi Anna, |
| Mit freundlichen Grüßen | Liebe Grüße |
| Freundliche Grüße | Viele Grüße |
| Mit freundlichen Grüßen und vielen Dank im Voraus | Bis bald! / Bis dann! |
|  | Ganz liebe Grüße / Alles Liebe |

Після звертання стоїть кома, а наступний рядок починається з малої літери: *Sehr geehrter Herr Schneider, ich schreibe Ihnen…*

## 2. Вступ: навіщо пишеш

Перший абзац закриває пункт «Grund für Ihr Schreiben». 1–2 речення.

### Formell

| Німецькою | Значення |
| --- | --- |
| Ich schreibe Ihnen, weil … | Пишу вам, тому що… |
| Ich wende mich an Sie, weil … / wegen … | Звертаюся до вас, тому що… / з приводу… |
| Ich möchte Sie über … informieren. | Хочу повідомити вам про… |
| Leider muss ich mich über … beschweren. | На жаль, змушений поскаржитися на… |
| Ich habe eine Frage zu … | У мене запитання щодо… |
| Vielen Dank für Ihr Schreiben vom 10. November. | Дякую за ваш лист від 10 листопада. |
| Wie ich Ihnen bereits am Telefon gesagt habe, … | Як я вже казав вам по телефону… |
| Ich habe Ihre Anzeige gelesen und interessiere mich für … | Я прочитав ваше оголошення і цікавлюся… |

### Informell

| Німецькою | Значення |
| --- | --- |
| Vielen Dank für deine E-Mail! | Дякую за листа! |
| Ich habe mich sehr über deine Nachricht gefreut. | Я дуже зрадів твоєму повідомленню. |
| Schön, mal wieder von dir zu hören! | Радий знову тебе чути! |
| Wie geht es dir? Mir geht es gut. | Як справи? У мене все добре. |
| Tut mir leid, dass ich mich erst jetzt melde. | Вибач, що пишу тільки зараз. |
| Ich schreibe dir, weil … | Пишу тобі, тому що… |
| Stell dir vor, …! | Уяви, …! |

## 3. Проблема, скарга, прохання

### Описати проблему

| Німецькою | Значення |
| --- | --- |
| Seit zwei Wochen funktioniert … nicht mehr. | Вже два тижні … не працює. |
| … ist kaputt / defekt. | … зламаний / зламана. |
| Ich habe ein Problem mit … | У мене проблема з… |
| Leider hat sich bis heute nichts geändert. | На жаль, досі нічого не змінилося. |
| Ich habe Sie bereits angerufen, aber seitdem ist nichts passiert. | Я вже телефонував, але відтоді нічого не сталося. |
| Ich bin mit … leider nicht zufrieden. | Я, на жаль, незадоволений… |
| Das ist für mich ein großes Problem, weil … | Для мене це велика проблема, тому що… |

### Попросити (пункт «Was Sie wollen»)

| Formell (Sie) | Informell (du) |
| --- | --- |
| Ich möchte Sie bitten, … zu … | Kannst du bitte …? |
| Könnten Sie bitte …? | Könntest du mir einen Gefallen tun? |
| Wären Sie so freundlich, … zu …? | Es wäre super, wenn du … könntest. |
| Es wäre sehr nett, wenn Sie … könnten. | Hast du vielleicht Zeit, …? |
| Ich erwarte, dass Sie … bis zum 30. November … | Sag mir bitte Bescheid, ob … |
| Bitte teilen Sie mir mit, wann … | Schreib mir einfach, wann … |

Запам'ятай: *bitten, … **zu** + інфінітив* (без *um*). *Ich möchte Sie bitten, die Fenster zu reparieren.*

## 4. Згода, відмова, пропозиція, вибачення, запитання

Ліворуч формально (Sie), праворуч неформально (du). Зміст за рядками: допомогти, відмовити, запропонувати, вибачитися, спитати, подякувати, побажати.

| Formell (Sie) | Informell (du) |
| --- | --- |
| Gern helfe ich Ihnen bei … | Na klar helfe ich dir! / Das mache ich gern! |
| Ich bin gern bereit, … zu … | Kein Problem, das ist doch selbstverständlich. |
| Leider kann ich … nicht, weil … | Es tut mir echt leid, aber ich kann leider nicht. |
| Ich muss Ihnen leider absagen. | Ich würde gern kommen, aber … |
| Ich schlage vor, dass … | Wie wäre es, wenn wir …? |
| Wäre es möglich, dass …? | Was hältst du davon, wenn …? |
| Darf ich vorschlagen, … | Wollen wir …? / Lass uns …! |
| Ich möchte mich für … entschuldigen. | Sorry, dass … / Es tut mir leid, dass … |
| Bitte entschuldigen Sie die Verspätung. | Sei mir bitte nicht böse! |
| Könnten Sie mir bitte sagen, ob / wann / wo …? | Weißt du schon, wann …? |
| Ich hätte noch eine Frage: … | Und noch eine Frage: … |
| Wo finde ich …? / Wann passt es Ihnen? | Wann passt es dir am besten? |
| Vielen Dank für Ihre Hilfe / Ihr Verständnis. | Danke dir! Das ist echt nett von dir. |
| Ich wünsche Ihnen alles Gute. | Ich wünsche dir einen schönen Urlaub! / Gute Besserung! |

## 5. Причини й наслідки

### Пояснити, чому це важливо або погано

| Німецькою | Значення |
| --- | --- |
| Das ist wichtig für mich, weil … | Це важливо для мене, тому що… |
| Ein großer Nachteil ist, dass … | Великий мінус у тому, що… |
| Außerdem kommt noch hinzu, dass … | До того ж додається те, що… |
| Das führt dazu, dass … | Це призводить до того, що… |
| Ich habe Angst, dass … | Я боюся, що… |
| Wenn …, dann … | Якщо…, то… |

### Що зробиш, якщо нічого не зміниться (типовий пункт у скаргах)

Завжди з конкретним терміном: *bis Freitag*, *innerhalb von drei Tagen*.

| Німецькою | Значення |
| --- | --- |
| Falls sich bis … nichts ändert, werde ich … | Якщо до… нічого не зміниться, я… |
| Sonst sehe ich mich gezwungen, … zu … | Інакше я буду змушений… |
| … mich an den Mieterverein / einen Anwalt wenden. | …звернутися до спілки орендарів / до адвоката |
| … die Miete kürzen. | …зменшити плату за оренду |
| … selbst einen Handwerker beauftragen und Ihnen die Rechnung schicken. | …сам викликати майстра і надіслати вам рахунок |
| … mein Geld zurückverlangen. | …вимагати гроші назад |
| … den Vertrag kündigen. | …розірвати договір |

## 6. Завершення і сполучники

| Formell (Sie) | Informell (du) |
| --- | --- |
| Ich freue mich auf Ihre Antwort. | Ich freue mich auf deine Antwort! |
| Über eine baldige Antwort würde ich mich sehr freuen. | Schreib mir bald! |
| Vielen Dank im Voraus. | Melde dich einfach! |
| Für Rückfragen stehe ich Ihnen gern zur Verfügung. | Ruf mich an, wenn du Fragen hast. |
| Vielen Dank für Ihr Verständnis. | Ich freue mich schon auf unser Treffen! |

*freuen auf* = чекаю з радістю (майбутнє). *freuen über* = радію тому, що є; з *würde* пишеться *über*.

### Сполучники (Konnektoren)

| Навіщо | Сполучники | Порядок слів |
| --- | --- | --- |
| Причина | weil, da | дієслово в кінці |
| Причина | denn | звичайний порядок |
| Наслідок | deshalb, deswegen, darum | дієслово одразу після сполучника |
| Додати | außerdem, zusätzlich, außerdem noch | дієслово одразу після сполучника |
| Протиставити | aber, sondern | звичайний порядок |
| Поступка | trotzdem | дієслово одразу після сполучника |
| Поступка | obwohl | дієслово в кінці |
| Умова | wenn, falls | дієслово в кінці |
| Мета | damit / um … zu | дієслово в кінці / zu + інфінітив у кінці |
| Послідовність | zuerst, dann, danach, zum Schluss | дієслово одразу після сполучника |
| Час | während, nachdem, bevor | дієслово в кінці |

У кожному листі намагайся вжити 5–6 різних сполучників. Це дає бали за критерій II.
