# Sprechen Teil 2: описати фото

Вісім зразків за фото з презентації «Prüfung DTZ Sprechen»: приблизно 10 речень про картинку (Teil A) і 10 речень про себе (Teil B). Особисті деталі (місто, родина, хобі) заміни своїми: розповідати про справжнє легше. Деякі ситуації у Teil B вигадані.

## Схема Teil 2 і правила на максимум

На B1 в Teil 2 треба назвати головне на фото **і деталі** (Teil A), а потім за питаннями екзаменатора докладно розповісти про свій досвід (Teil B). На A2 вистачає короткого загального опису, тому деталі й приклади й дають різницю.

### Teil A: картинка (близько 10 речень)

1. Тема: *Auf meinem Foto geht es um das Thema …*
2. Люди: хто, скільки, вік, одяг.
3. Дія: що вони роблять просто зараз.
4. Місце й час: де, яка пора року чи доби, чому так думаєш.
5. Атмосфера: як люди виглядають, що відчувають.
6. Здогад: ким вони одне одному доводяться, що було до або буде потім.

### Teil B: про себе (близько 10 речень)

1. Як це в тебе зараз (Präsens).
2. Конкретний випадок із минулого (Perfekt + *als ich … war*).
3. Порівняння України й Німеччини.
4. Своя думка або план на майбутнє.

### Правила

- Відкривай речення по-різному (*Im Vordergrund… / Rechts… / Ich vermute…*), не тільки *Ich sehe…*
- Здогади показуй як здогади й пояснюй: *Ich glaube, dass …, weil …*
- У Teil B використовуй три часи: зараз, раніше, в майбутньому. Це одразу звучить як B1.
- Не зупиняйся після одного речення: відповідь + причина + приклад.
- Не знаєш слово? Опиши його: *so ein Ding, mit dem man …*
- Теми з презентації йдуть парами (два фото про прибирання, про лікаря, про банк…). Текст нижче легко перенести на друге фото з пари.
- З екзаменатором завжди на *Sie*. З партнером по іспиту зазвичай на *du*, якщо ви так домовилися.

## Фрази

### Teil A: описати фото

| Навіщо | Фрази |
| --- | --- |
| Тема | Auf meinem Foto geht es um das Thema … · Das Thema des Bildes ist … · Das Foto zeigt eine typische Situation aus dem Alltag. |
| Де на фото | Im Vordergrund / Im Hintergrund sieht man … · In der Mitte / Links / Rechts steht … · Oben / Unten … |
| Люди | Auf dem Bild sieht man …, die … · Die Frau ist ungefähr 30 Jahre alt. · Sie trägt eine Jeans und einen Pullover. · Die Personen sehen … aus. |
| Дія | Die Personen sind gerade dabei, … zu … · Es sieht so aus, als ob … · Man kann deutlich erkennen, dass … |
| Місце й час | Die Personen befinden sich in … · Das könnte im Herbst sein, weil … · Ich vermute, dass es Nachmittag ist, denn … |
| Атмосфера | Hier herrscht eine warme / angenehme / entspannte Stimmung. · Sie haben gute Laune. · Sie wirkt gestresst / nachdenklich. · Sie scheinen zufrieden zu sein. |
| Здогад | Ich glaube, dass … · Vielleicht sind sie … · Wahrscheinlich … · Ich bin mir nicht sicher, aber … |
| Проблема / думка | Das Foto spricht das Problem … an. · Wenn ich das Foto anschaue, denke ich sofort an … |

### Teil B: про себе

| Навіщо | Фрази |
| --- | --- |
| Почати | Bei mir persönlich ist das ähnlich / ganz anders. · Diese Situation kenne ich sehr gut. · Das erinnert mich an … |
| Минуле | Als ich noch Kind war, … · Als ich in der Ukraine gewohnt habe, … · Letztes Jahr habe ich … · Früher habe ich oft …, heute … |
| Порівняти | In meinem Heimatland ist das ein bisschen anders: … · Im Vergleich zur Ukraine … · In Deutschland ist mir aufgefallen, dass … · Ich könnte mir gut vorstellen, dass man so ein Foto auch bei uns macht. |
| Думка | Ich finde es wichtig, dass … · Meiner Meinung nach … · Der Vorteil ist, dass … |
| Майбутнє | In Zukunft möchte ich … · Mein Traum ist es, … zu … · Ich habe vor, … |
| Виграти час | Das ist eine gute Frage. · Moment, lassen Sie mich kurz überlegen. · Wie soll ich sagen … |
| Не зрозумів питання | Entschuldigung, könnten Sie die Frage bitte wiederholen? · Meinen Sie, ob …? |

## Восьмі фото: слухати й повторювати

Для кожного фото є Teil A, Teil B, можливий варіант і запитання екзаменатора. Озвучено чоловічим голосом; пару голосів (Німеччина або Австрія) і темп можна змінити. Корисно слухати Teil A, потім самому розповісти Teil B своїми словами.
