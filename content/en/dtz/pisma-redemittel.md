# Phrases for letters (Redemittel)

Universal phrases for every kind of DTZ letter: formal (Sie) and informal (du). Choose phrases that sound good and are really used. Letter rules are on [Letter rules](#/dtz/pisma-pravila).

## 1. Greeting and closing

| Formell (Sie) | Informell (du) |
| --- | --- |
| Sehr geehrter Herr Schneider, | Lieber Max, / Liebe Anna, |
| Sehr geehrte Frau Müller, | Hallo Max, |
| Sehr geehrte Damen und Herren, | Hi Anna, |
| Mit freundlichen Grüßen | Liebe Grüße |
| Freundliche Grüße | Viele Grüße |
| Mit freundlichen Grüßen und vielen Dank im Voraus | Bis bald! / Bis dann! |
|  | Ganz liebe Grüße / Alles Liebe |

A comma follows the greeting and the next line starts with a small letter: *Sehr geehrter Herr Schneider, ich schreibe Ihnen…*

## 2. Introduction: why you write

The first paragraph covers the point "Grund für Ihr Schreiben". 1–2 sentences.

### Formell

| German | Meaning |
| --- | --- |
| Ich schreibe Ihnen, weil … | I am writing to you because … |
| Ich wende mich an Sie, weil … / wegen … | I am contacting you because … / regarding … |
| Ich möchte Sie über … informieren. | I would like to inform you about … |
| Leider muss ich mich über … beschweren. | Unfortunately I have to complain about … |
| Ich habe eine Frage zu … | I have a question about … |
| Vielen Dank für Ihr Schreiben vom 10. November. | Thank you for your letter of 10 November. |
| Wie ich Ihnen bereits am Telefon gesagt habe, … | As I already told you on the phone, … |
| Ich habe Ihre Anzeige gelesen und interessiere mich für … | I read your advert and I am interested in … |

### Informell

| German | Meaning |
| --- | --- |
| Vielen Dank für deine E-Mail! | Thanks for your email! |
| Ich habe mich sehr über deine Nachricht gefreut. | I was really happy about your message. |
| Schön, mal wieder von dir zu hören! | Nice to hear from you again! |
| Wie geht es dir? Mir geht es gut. | How are you? I am fine. |
| Tut mir leid, dass ich mich erst jetzt melde. | Sorry that I am only getting in touch now. |
| Ich schreibe dir, weil … | I am writing to you because … |
| Stell dir vor, …! | Imagine, …! |

## 3. Problem, complaint, request

### Describe the problem

| German | Meaning |
| --- | --- |
| Seit zwei Wochen funktioniert … nicht mehr. | For two weeks … has not been working. |
| … ist kaputt / defekt. | … is broken / defective. |
| Ich habe ein Problem mit … | I have a problem with … |
| Leider hat sich bis heute nichts geändert. | Unfortunately nothing has changed so far. |
| Ich habe Sie bereits angerufen, aber seitdem ist nichts passiert. | I have already called you, but nothing has happened since. |
| Ich bin mit … leider nicht zufrieden. | Unfortunately I am not satisfied with … |
| Das ist für mich ein großes Problem, weil … | This is a big problem for me because … |

### Ask for something (point "Was Sie wollen")

| Formell (Sie) | Informell (du) |
| --- | --- |
| Ich möchte Sie bitten, … zu … | Kannst du bitte …? |
| Könnten Sie bitte …? | Könntest du mir einen Gefallen tun? |
| Wären Sie so freundlich, … zu …? | Es wäre super, wenn du … könntest. |
| Es wäre sehr nett, wenn Sie … könnten. | Hast du vielleicht Zeit, …? |
| Ich erwarte, dass Sie … bis zum 30. November … | Sag mir bitte Bescheid, ob … |
| Bitte teilen Sie mir mit, wann … | Schreib mir einfach, wann … |

Remember: *bitten, … **zu** + infinitive* (no *um*). *Ich möchte Sie bitten, die Fenster zu reparieren.*

## 4. Agreeing, refusing, suggesting, apologising, asking

Formal (Sie) on the left, informal (du) on the right. Meaning by row: help, refuse, suggest, apologise, ask, thank, wish well.

| Formell (Sie) | Informell (du) |
| --- | --- |
| Gern helfe ich Ihnen bei … | Na klar helfe ich dir! / Das mache ich gern! |
| Ich bin gern bereit, … zu … | Kein Problem, das ist doch selbstverständlich. |
| Leider kann ich … nicht, weil … | Es tut mir echt leid, aber ich kann leider nicht. |
| Ich muss Ihnen leider absagen. | Ich würde gern kommen, aber … |
| Ich schlage vor, dass … | Wie wäre es, wenn wir …? |
| Wäre es möglich, dass …? | Was hältst du davon, wenn …? |
| Darf ich vorschlagen, … | Wollen wir …? / Lass uns …! |
| Ich möchte mich für … entschuldigen. | Sorry, dass … / Es tut mir leid, dass … |
| Bitte entschuldigen Sie die Verspätung. | Sei mir bitte nicht böse! |
| Könnten Sie mir bitte sagen, ob / wann / wo …? | Weißt du schon, wann …? |
| Ich hätte noch eine Frage: … | Und noch eine Frage: … |
| Wo finde ich …? / Wann passt es Ihnen? | Wann passt es dir am besten? |
| Vielen Dank für Ihre Hilfe / Ihr Verständnis. | Danke dir! Das ist echt nett von dir. |
| Ich wünsche Ihnen alles Gute. | Ich wünsche dir einen schönen Urlaub! / Gute Besserung! |

## 5. Reasons and consequences

### Explain why it matters or is bad

| German | Meaning |
| --- | --- |
| Das ist wichtig für mich, weil … | This is important to me because … |
| Ein großer Nachteil ist, dass … | A big disadvantage is that … |
| Außerdem kommt noch hinzu, dass … | On top of that, … |
| Das führt dazu, dass … | This leads to … |
| Ich habe Angst, dass … | I am afraid that … |
| Wenn …, dann … | If …, then … |

### What you will do if nothing changes (typical point in complaints)

Always with a concrete deadline: *bis Freitag*, *innerhalb von drei Tagen*.

| German | Meaning |
| --- | --- |
| Falls sich bis … nichts ändert, werde ich … | If nothing changes by …, I will … |
| Sonst sehe ich mich gezwungen, … zu … | Otherwise I will be forced to … |
| … mich an den Mieterverein / einen Anwalt wenden. | …turn to the tenants' association / a lawyer |
| … die Miete kürzen. | …reduce the rent |
| … selbst einen Handwerker beauftragen und Ihnen die Rechnung schicken. | …hire a tradesman myself and send you the bill |
| … mein Geld zurückverlangen. | …demand my money back |
| … den Vertrag kündigen. | …cancel the contract |

## 6. Endings and connectors

| Formell (Sie) | Informell (du) |
| --- | --- |
| Ich freue mich auf Ihre Antwort. | Ich freue mich auf deine Antwort! |
| Über eine baldige Antwort würde ich mich sehr freuen. | Schreib mir bald! |
| Vielen Dank im Voraus. | Melde dich einfach! |
| Für Rückfragen stehe ich Ihnen gern zur Verfügung. | Ruf mich an, wenn du Fragen hast. |
| Vielen Dank für Ihr Verständnis. | Ich freue mich schon auf unser Treffen! |

*freuen auf* = look forward to (future). *freuen über* = be glad about what is there; with *würde* use *über*.

### Connectors (Konnektoren)

| Purpose | Connectors | Word order |
| --- | --- | --- |
| Reason | weil, da | verb at the end |
| Reason | denn | normal order |
| Result | deshalb, deswegen, darum | verb right after the connector |
| Add | außerdem, zusätzlich, außerdem noch | verb right after the connector |
| Contrast | aber, sondern | normal order |
| Concession | trotzdem | verb right after the connector |
| Concession | obwohl | verb at the end |
| Condition | wenn, falls | verb at the end |
| Purpose | damit / um … zu | verb at the end / zu + infinitive at the end |
| Sequence | zuerst, dann, danach, zum Schluss | verb right after the connector |
| Time | während, nachdem, bevor | verb at the end |

Try to use 5–6 different connectors in every letter. That earns points in criterion II.
